# クイズ勉強帳

みんはや（みんなで早押しクイズ）対策用の学習アプリ。国旗・首都、日本史・中国史・古代世界史、各種の賞（文学・映画・音楽）を、一覧表・暗記カード・4択／入力クイズで体系的に覚える。

- 苦手（間違えた問題）を優先して出題し、2回続けて正解すると「習得」
- 入力モードは表記ゆれ（カタカナ／ひらがな、全角／半角、記号、別解）を吸収する
- 一覧表では列を隠して暗記できる。ホームでは全データを横断検索できる

## データの管理

| 置き場所 | 用途 | 追加方法 |
|---|---|---|
| GitHub `data/*.json` | 基本データ（体系的に整備した表） | JSON を編集して push（形式は [data/SCHEMA.md](data/SCHEMA.md)）。新しいファイルを足したら `python3 tools/build_index.py` |
| Google スプレッドシート | 追加データ・自作デッキ・学習記録 | アプリの「＋追加」「新しいデッキを作る」、またはシートを直接編集 |

スプレッドシートのシート名ルール：
- デッキID（例 `award-akutagawa`）→ そのデッキに行を追加（1行目は列キー）
- `カテゴリ/タイトル`（例 `地理/日本の都道府県`）→ 新しいデッキ（1行目は見出し、1列目が問題の軸）
- `_` で始まるシート → システム用（`_progress` は学習記録）

## 構成

- フロント: GitHub Pages（`index.html`, `app.js`, `style.css`, `config.js`）。ビルド不要
- バックエンド: Google Apps Script（`gas/Code.gs`）+ スプレッドシート

## GAS のセットアップ（初回のみ）

1. https://script.google.com で新しいプロジェクト「クイズ勉強帳」を作成し、`gas/Code.gs` を貼り付けて保存
2. 関数 `setup` を実行（権限を許可）→ スプレッドシート「クイズ勉強帳データ」が作られる
3. プロジェクトの設定 → スクリプトプロパティに `PASSCODE`（合言葉）を追加
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」
5. 表示された `/exec` URL を `config.js` の `GAS_URL` に書いて push（またはアプリの設定画面に入力）
6. アプリの設定画面で合言葉を入力 →「保存して接続テスト」

コードを更新したときは「デプロイを管理 → 編集 → バージョン: 新バージョン」で URL を変えずに反映する。

## ローカルで動かす

```bash
python3 -m http.server 8000
```
